# OBJETIVO PRINCIPAL DEL SITIO

Permitir que clientes puedan reservar citas directamente desde la página web.

La reserva debe reducir pasos manuales y conectarse con las herramientas que ya utiliza el negocio.

Objetivo final:

Cliente entra al sitio
→ selecciona servicio
→ selecciona fecha y horario
→ realiza pago en línea
→ la cita queda registrada automáticamente

El negocio actualmente utiliza Google Calendar para administrar citas.

El sitio debe considerar integración con Google Calendar para registrar automáticamente nuevas reservas.

También se desea integrar pagos en línea para automatizar el proceso de reserva.
